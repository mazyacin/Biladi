# Biladi – A Flutter Framework for Tourist Guide Apps

**Biladi is a customizable Flutter framework for building tourist guidance apps.** 

It comes with a **fully working example for Algeria**, but the framework itself is country-agnostic – you can rebrand it for any city, region, or even food tours in 5 minutes by editing a single file.

**This is an Android (APK) app built with Flutter/Dart.**

## 🎯 What Is This?

This project started as a tourist app for Algeria, but evolved into a **reusable template** that anyone can use to create their own tourist guide app.

**Key Features:**
- Full tourist guide structure (places, descriptions, images)
- Clean, modern UI built with Flutter
- Easy to rebrand – change the some code and your done ( even if you dont know how to its explained in the /Explained folder
- Works on Android (APK) and iOS (if built from source)
